# 磁盘治理 v2

按**可再生性**分层的本地磁盘清理工具。零第三方依赖，离线可用，只监听 127.0.0.1。

配套策略文档：`清理策略.md`（规则怎么来的、为什么这么做，都在里面）。

---

## 启动

双击 `启动工具.cmd`，浏览器自动打开 `http://127.0.0.1:7790`。
关掉黑窗口即退出，不装服务、不写注册表、不留后台进程。端口被占会自动顺延到 7791、7792…

命令行方式（便于调试）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "$env:DISKGOV_NO_OPEN='1'; node server.js"
```

## v1 → v2 改了什么

| 问题（v1） | 处理（v2） |
|---|---|
| 把「长期未用」「大文件」算进可释放 | 降级为「线索」，单独放在「待判断」页，**永不进入清理清单** |
| 浏览器缓存当一个整体清 | 拆到子目录：只清 Cache / Code Cache / GPUCache / CacheStorage / ShaderCache |
| 不知道 `Local Storage` 里存的是登录态 | 新增 L0 规则 `browser_profile_data` 硬拦截，密码、书签、Cookie、IndexedDB 全部锁死 |
| 客户端开着也照清 | 每条规则可声明 `noProcess`，检测到进程在跑就整类跳过，并给出「关掉后重新检测」按钮 |
| 可释放数字虚高 | 拆成「现在就能清」与「需先关程序」两个数，不混报 |
| 类目只有安全/谨慎/受保护 | 四层 L0–L3，层次直接决定能不能进清单 |
| 单次清理无上限 | 超过 20GB 必须显式 `force` 才生成清单 |

## 四层分级

| 层 | 含义 | 允许动作 | 本机实测 |
|---|---|---|---|
| **L1** 可再生·零代价 | 程序或网络能完整重建，重建无感知 | 可直接清 | 9.76 GB |
| **L2** 可再生·有代价 | 能重建，但要重下、重建索引、丢历史 | 条件清理，逐项确认 | 2.01 GB |
| **L3** 仅迁移 | 不可再生，删了没有第二份 | 只能移到其他盘 | 2.46 GB |
| **L0** 禁动 | 删了会坏系统/程序，或属唯一副本 | 仅报告 | 6.60 GB |

**判定三问**（缺一不可）：
① 删了软件或网络能不能再生成一份一样的？ ② 重新生成要付什么代价？ ③ 它是不是唯一副本？
只要 ③ 是「是」，无论多大、多久没动，都不进清单。

## 五个页面

- **空间概览**：磁盘水位、现在能清多少、四层汇总、五阶段预算、目录/类型/年龄分布、建议处理顺序
- **分类与分层**：按 L1→L2→L3→L0 排列，每张卡带判断依据、前置条件、证据串、可勾选状态
- **重复与相似**：完全重复按内容哈希确认，给保留建议但**不自动清**；相似文件名只作提示
- **待判断**：大文件与长期未用，明确标注"不进清单"
- **策略与规则**：29 条规则的清单，含分层、前置条件、是否可清

## 安全边界

**四道闸，任何一道命中都不动文件：**

1. **规则分层**：L0/L3/hold 类目在引擎层就不可选，界面禁用只是表象
2. **白名单**：`config.json` 里的 glob，优先级高于所有规则
3. **服务端二次校验**：生成清单时校验一次，执行移动时再校验一次（防「生成时合规、执行时被改」）
4. **占用与进程检测**：移动前逐个 `r+` 试打开，EBUSY/EPERM 跳过；执行前重新检查 `noProcess`

**移动而非删除**：文件落到 `D:\磁盘治理备份\yyyyMMddHHmmss\<规则id>\<原相对路径>`，同目录生成：
- `_移动清单.csv` — 每个文件的 src/dst/size/cat
- `_还原.ps1` — 双击即原样搬回

**逐条校验**：只有确认源路径真的消失，才计入「已释放」。跨卷移动失败会单独报，不会算成成功。

## 已知边界

- **扫描整盘 C: 约 1.5–3 分钟**（40 万文件 / 100 秒量级）。扫 `C:\Users\<你>` 更快。
- 重复检测只覆盖 ≥1MB 的文件；同体积文件超过 60 个时跳过，避免在大目录上耗时。
- 需要管理员权限的目录（WinSxS、部分 System32）读不到时计入「无权限」，不报错。
- **DISM 组件清理、驱动清理、程序卸载不在工具内**：这三件事不能靠文件操作完成，工具只在预算表里提示。
- 系统关闭了「最后访问时间」更新时，年龄只能按修改时间算，界面会说明当前用的是哪种。
- 扫描期间照常用电脑不会打断，但**不要关闭那个命令行窗口**。

## 建议用法

1. 扫 `C:\`，看「现在就能清」是多少
2. 「分类与分层」点「只选 L1」→ 生成清单 → 试运行 → 执行
3. 关掉汽水音乐 / 浏览器 / 微信，回概览点「重新检测」，再清 L1 剩下的
4. 用一天，确认软件都正常
5. 再做 L2（IntelliJ 索引会重建，慢几分钟属正常）
6. L3 用系统自带的「属性 → 位置 → 移动」迁到 D 盘，不要用工具
7. 观察满 7 天，再删 D 盘备份
