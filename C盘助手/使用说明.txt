C盘助手  v1.0
================================================

一个本地可视化清理工具。所有操作都是"移动到 D 盘备份区"，
不永久删除任何文件，可随时还原。

一、怎么用
------------------------------------------------
双击 启动工具.cmd
浏览器会自动打开 http://127.0.0.1:7788
关掉那个黑色命令行窗口 = 退出工具

二、界面怎么理解
------------------------------------------------
1. 上方两张卡：C 盘 / D 盘 实时的可用空间与占用比例
   C 盘到 90% 会标红，低于 15GB 就该清了

2. 中间列表：可清理的 8 类内容
   每行右边是体积和文件数，带风险标签
     [安全]     随便清，不影响任何功能
     [谨慎]     清了有代价（要重建缓存/索引，或需先关掉程序）
     [需管理员] 要在管理员 PowerShell 里才能移动

   单个勾选，或点右上角"只选安全项"

3. 底部条：算出选中的总体积，点"开始清理"
   进度走完会显示实际腾出多少 GB

4. "查看清理记录"：历次清理的时间和释放量

三、文件都去哪了
------------------------------------------------
D:\C盘清理备份\yyyyMMdd-HHmmss\
  ├─ 01-更新器残留\
  ├─ 02-临时文件\
  ├─ 06-汽水音乐\
  └─ _移动清单.csv   ← 每个文件的原始路径都记在这里

想还原：按清单里的 src 字段搬回原位即可。
确认一切正常后，直接删掉整个日期目录即可释放 D 盘。

四、安全边界
------------------------------------------------
不会碰的东西：
  WinSxS / DriverStore / WindowsApps / Windows\Installer
  System32 / 已安装程序目录 / 你的文档

移动前会自动跳过：正在被程序占用、删不掉的文件

注意：
  - 清理浏览器缓存前最好先关浏览器
  - 清理 IntelliJ 缓存前先关 IDE，下次打开会重建索引（慢几分钟）
  - 汽水音乐缓存建议在客户端设置里清，避免占用导致跳过

五、出问题了
------------------------------------------------
浏览器打不开？
  看命令行窗口是不是启动了；端口被占会自动换到 7789/7790

提示找不到 Node.js？
  装个 Node.js，或把 node.exe 的路径写进 启动工具.cmd 的 NODE_EXE

想改扫描范围？
  编辑 core.ps1 里的 Get-Defs 函数，照着现有格式加一条即可
  （改完要用记事本另存为 UTF-8 带 BOM，否则 PowerShell 5.1 会乱码）

文件清单
  core.ps1      扫描与移动逻辑（PowerShell）
  server.js     本地服务，无第三方依赖
  ui.html       界面，单文件、离线可用
  启动工具.cmd  入口
